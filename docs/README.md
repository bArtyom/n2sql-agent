# 文档导航

## `plans/`

保存当前有效的计划，按层级阅读：

- [总体计划](plans/总体计划.md)：项目方向、长期目标与阶段验收边界。
- [第一阶段：知识库平台最小闭环](plans/第一阶段-知识库平台.md)：当前正在执行的阶段计划、实施顺序与验收标准。

总体计划只说明“做什么”和阶段边界；阶段计划说明“本阶段如何做”。计划变更时优先更新阶段计划，再同步总体计划。

## `conversations/`

保存影响后续开发的需求确认、关键决策和进度记录，不作为实施规范的唯一来源。文件按 `YYYY-MM-DD-主题.md` 命名，并记录背景、已确认结论、当前进度、下一步与待确认事项。

## 维护规则

- 新阶段在 `plans/` 下新增独立计划文件。
- 已确认、可执行的范围与验收标准必须写入对应阶段计划。
- 对话中形成的决策摘要写入 `conversations/`，并同步到受影响的计划。
