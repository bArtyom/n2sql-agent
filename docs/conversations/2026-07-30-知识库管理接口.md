# 知识库管理接口

## 背景

知识库、文档和处理任务的数据表已建立。本小步仅实现知识库的增、查、删，不涉及文件上传与 Worker。

## 已实现接口

- `POST /api/knowledge-bases` 以 `{"name":"...","description":"..."}` 创建知识库，成功返回 `201` 与新建资源。
- `GET /api/knowledge-bases` 返回当前本地管理员的知识库列表。
- `DELETE /api/knowledge-bases/{id}` 删除指定知识库，成功返回 `204`。

## 分层

```text
main 创建 db 与 knowledgebase.PostgresStore
  -> app 注册 URL
  -> handler 解析 JSON、校验、返回 HTTP 状态
  -> PostgresStore 执行 SQL
  -> PostgreSQL
```

## 安全与约束

- 创建接口拒绝未知 JSON 字段、空名称、超大请求、超长名称或描述。
- 重复名称返回 `409 Conflict`。
- 删除不存在的知识库返回 `404 Not Found`。
- 单管理员模式下，Store 从 `system_settings` 读取本地管理员 ID，只操作其名下的知识库。
