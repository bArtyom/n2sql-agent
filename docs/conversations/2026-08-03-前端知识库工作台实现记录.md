# 前端知识库工作台实现记录

## 背景

第一阶段后端已经具备知识库、文档上传、Worker 处理、语义检索、非流式问答和 SSE 流式问答能力。本次按 WeKnora 的产品形态重新建设 `n2sql-agent` 自己的 Vue 前端，不复制参考项目源码，也不引入 N2SQL/schema 相关内容。

## 已完成

- 将原来的前端占位首页改为单页知识库工作台：左侧知识库导航与创建表单，中间资料架，右侧问答台。
- 接入 `GET/POST /api/knowledge-bases`，支持加载、创建和切换知识库。
- 接入 `POST /api/knowledge-bases/{id}/documents`，支持拖拽或选择 Markdown、TXT 上传；PDF 入口暂时关闭，避免在解析器未完成时产生必然失败的任务。
- 新增 `GET /api/knowledge-bases/{id}/documents`，返回文档元数据及最新处理状态；前端对 `pending/processing` 自动轮询。
- 接入 `POST /api/knowledge-bases/{id}/chat/stream`，前端用 `ReadableStream` 消费 `sources/delta/done/error` SSE 事件，逐字显示答案并展开引用段落。
- 修正 SSE 增量更新使用 Vue 响应式数组中的对象，确保流式内容在事件到达时立即刷新。
- 上传区域补充键盘触发和按钮语义，支持焦点可见与辅助技术使用。
- 增加响应式布局、移动端侧栏、键盘焦点样式和 `prefers-reduced-motion` 兼容。

## 验证

- `npm run build` 通过（`vue-tsc --noEmit && vite build`）。
- 真实浏览器打开 `http://127.0.0.1:5173/`，确认空知识库状态页、创建表单、错误提示和整体布局可见；浏览器控制台无 warn/error。
