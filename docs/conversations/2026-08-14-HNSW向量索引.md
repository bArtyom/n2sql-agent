# HNSW 向量索引

## 背景

父子 chunk 重置后，当前子块 embedding 维度均为 1024。之前 `embedding` 使用无维度 `vector`，pgvector 无法在这种列上创建 HNSW 索引。

## 实现

- 新增迁移 `000017_add_chunk_embedding_hnsw_index.up.sql`。
- 将 `document_chunks.embedding` 明确为 `vector(1024)`。
- 使用 `vector_cosine_ops` 创建部分 HNSW 索引，只索引非空 embedding。
- 现有 RAG、Agent 和搜索 SQL 不变，查询会由 PostgreSQL 选择是否使用索引。

## 验证

- 数据库现有 embedding：36 条，全部为 1024 维。
- HNSW 索引已创建。
- 关闭顺序扫描后，`EXPLAIN` 显示使用 `document_chunks_embedding_hnsw_idx`。
- 小数据量时 PostgreSQL 可能主动选择顺序扫描，这是正常的成本优化。
