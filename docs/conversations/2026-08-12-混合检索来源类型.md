# 混合检索来源类型

## 背景

混合检索同时走 pgvector 语义检索和 PostgreSQL 关键词包含检索。关键词路径为了复用统一结果结构，会把 `distance` 填为 0；如果只看 distance，用户容易误以为这是向量距离。

## 已确认实现

- `documentchunk.SearchResult.MatchType` 标记单路结果来源：`vector` 或 `keyword`。
- `retrieval.mergeResults` 按 `document_id:position` 去重；同一片段同时命中两路时升级为 `hybrid`。
- Agent/RAG 原有返回结构不变，只增加可选的 `matchType` 字段。
- 前端引用卡片和详情面板显示“语义命中 / 关键词命中 / 双路命中”。

## 调用链

`PostgresStore.Search/ SearchKeyword` 设置来源 → `retrieval.NewHybridService` 合并并去重 → 现有距离阈值和 topK 过滤 → Agent/RAG 返回 sources → 前端引用卡片展示来源类型。
