# 语义检索实现记录

## 背景

文档块已经可以由 Worker 调用 Embedding 模型并保存到 pgvector。下一步需要验证用户问题能否检索出对应文本块。

## 已完成

- 新增 `retrieval.Service`：将用户问题作为单条输入向量化，再调用文本块存储层检索。
- 新增 `documentchunk.PostgresStore.Search`：限制在指定知识库内，使用 pgvector `<=>` 距离排序并返回 `documentId`、`position`、`content` 和 `distance`。
- 新增 `POST /api/knowledge-bases/{id}/search`，请求格式为 `{"query":"...","limit":5}`，最多返回 20 个结果。
- 在 `main` 和 `app` 中装配检索服务；检索结果暂不交给 Chat 模型。

## 验证

- `go test ./...`
- `go vet ./...`
- `git diff --check`

## 当前限制与下一步

- 目前只完成“问题 → 相似文本块”，尚未生成最终回答、SSE 流式输出或引用展示。
- `embedding` 列暂未声明固定维度，也尚未创建向量索引；需要确定实际 Embedding 模型后再处理索引与维度约束。
- 下一步将检索结果拼接为 Chat 上下文，完成最小非流式 RAG 问答。
