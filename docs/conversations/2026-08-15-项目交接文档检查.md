# 项目交接文档检查

## 背景

用户确认：希望开发记录、学习笔记、个性化开发要求和当前进度能够让另一个 Agent 通过阅读文件快速接手。

## 检查结论

- `AGENTS.md` 已保存软件工程原则、学习式提问、WeKnora 参考边界、验证要求、对话记录规则和 Git 约定。
- `docs/plans/` 已保存总体计划、第一阶段计划、第二阶段 Agent/后端计划和学习与面试计划。
- `docs/conversations/` 已保存从启动、Go 分层、RAG、Agent、检索、引用、工具轨迹、MCP/A2A 到最近追问建议的专题记录。
- `docs/` 按约定被 Git 忽略，因此适合当前机器上的学习资料，但重新克隆项目时不会自动出现。
- 新增根目录 `PROJECT_STATUS.md` 作为版本化交接摘要，记录项目边界、当前能力、后置项、最新提交和下一步工作方式；README 已指向该文件。

## 已确认结论

- `n2sql-agent` 是唯一独立实现，WeKnora 只作参考。
- 当前主线继续优先 Agent/RAG 用户可见能力；不主动引入 SQL/schema/N2SQL、Redis、完整协议或大规模评测。
- 成功回答后的编辑/覆盖式重新生成不在当前范围内。
