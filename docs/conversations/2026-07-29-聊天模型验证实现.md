# 聊天模型验证实现

## 背景

第一阶段先完成通用文档知识库问答平台，不引入 N2SQL 或 Schema 相关范围。模型 Provider 配置已存入数据库，API Key 只留在本地 `.env`。

## 已确认结论

- 新增 `POST /api/model-provider/chat-test`，请求体为 `{"message":"..."}`。
- 请求流程为 `main → app → handler → ChatService → 共享 HTTPClient → 模型服务`。
- 使用已保存的 `chatModel` 调用 OpenAI 兼容的 `/chat/completions`，强制非流式调用，回传第一条模型回答。
- 复用现有的 HTTPS、主机名白名单、禁止重定向、请求超时、响应大小限制与 API Key 环境变量校验。

## 验证与待办

- 单元测试覆盖成功、缺少密钥、请求非法和远端模型调用失败的路径。
- 未填入真实 API Key，因此未发起付费的远端模型请求。
- 下一步是知识库、文档、文档处理任务的数据模型与迁移。
