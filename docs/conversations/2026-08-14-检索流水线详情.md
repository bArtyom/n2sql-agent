# 检索流水线详情

## 背景

后端已经为一次 RAG/Agent 运行记录了检索统计，前端原先只显示一行简短数字。为了更容易学习和排查，本轮把这组统计做成可展开的详情面板。

## 已确认结论

- 不新增检索算法、模型调用或数据库字段。
- 详情只展示有界计数和状态，不展示 API Key、查询改写文本或完整内部错误。
- 面板按流水线阶段解释数字：向量召回、关键词召回、关键词阈值过滤、混合去重、Rerank、最终距离过滤。
- Rerank 未配置和 Rerank 失败要区分：前者显示未执行，后者显示已降级并继续使用混合召回结果。

## 实现位置

- `frontend/src/App.vue`：增加展开状态、详情字段和说明。
- `frontend/src/styles.css`：增加详情网格和移动端两列布局。
- `README.md`：补充使用说明。
