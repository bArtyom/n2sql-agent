# 会话内模型切换实现

## 背景

对照 WeKnora 的会话能力，当前 Provider 只有一个固定 `chatModel`，重新打开会话时不能选择其他已配置的聊天模型。用户确认继续开发这一切片。

## 已确认结论

- 本轮只切换标准 Agent 的聊天模型；Embedding、Rerank、协作研究和 A2A 继续使用现有配置。
- 模型列表由服务端 Provider 配置维护，浏览器只能提交模型 ID，不能提交 Base URL 或 API Key。
- 会话保存 `chatModel`，切换后刷新或重新打开会话仍恢复；空值表示使用 Provider 默认模型。
- 未配置 Provider、未知模型和跨知识库会话由服务端拒绝，不把模型选择权限交给前端。

## 已完成

- `model_providers.chat_models` 和 `conversations.chat_model` 数据迁移。
- Provider 模型列表去空格、去重、数量/长度限制和 allowlist 校验。
- 会话 PATCH、Agent 请求、Chat runtime 和前端选择器接通。
- 模型设置抽屉支持逗号分隔的可选聊天模型列表。
- 增加正常路径、未知模型、会话归属和 runtime 透传测试。

## 验证

- 通过：相关 Go 包测试、`go vet`、前端 `npm run build`。
- 未完全通过：`go test ./...` 仍有仓库原有文档文件路径、PDF/OCR 外部命令和 Worker 相关测试失败；新增模型相关包没有失败。
