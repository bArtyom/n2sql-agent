# 父块上下文去重

## 背景

多个子块可能属于同一个父块。如果每个子块都携带完整父块，模型上下文会重复，浪费 token。

## 实现

- `retrieval.PromptContext` 在一次 prompt 构造期间记录已注入的父块。
- 第一个命中子块使用“父块上下文 + 命中片段”。
- 同一父块后续命中只使用“命中片段”，但不删除原始 source。
- RAG 和 Agent 工具都复用同一套 32KB 字节限制。

## 边界

- 前端返回的 sources 仍然保留所有子块、分数和位置。
- 去重只影响发给模型的内容，不影响检索结果和引用展示。
- 当前限制按 UTF-8 字节计算，不是精确 token 数。
