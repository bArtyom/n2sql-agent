# 回答 Markdown 渲染

## 背景

当前 Agent 的回答以纯文本显示，标题、列表、引用和代码块会失去结构。WeKnora 的聊天主链路会把回答按 Markdown 展示，因此本轮补一个前端可见的小切片，不改变后端 SSE、会话或模型协议。

## 实现

- 新增 `frontend/src/utils/markdown.ts`，使用 `marked` 把回答转换为 HTML。
- 使用 `DOMPurify` 做第二层清理，去掉脚本、表单、iframe、图片、SVG 和样式等高风险内容。
- 外链统一设置 `target="_blank"` 和 `rel="noopener noreferrer"`。
- Vue 只对已经完成的助手回答使用 `v-html`；流式中和错误回答仍使用纯文本，避免半截 Markdown 造成布局抖动或把错误内容当 HTML。
- 增加标题、列表、引用、行内代码、代码块、表格和链接的基础样式。

## 调用链

```text
模型 message_delta
  → ChatMessage.content 累积
  → run_finished 后 status=done
  → renderCompletedAnswer
  → marked.parse
  → DOMPurify.sanitize
  → v-html 渲染安全 HTML
```

## 注意事项

- `v-html` 只能接收经过清理的字符串，不能直接插入模型原文。
- Markdown 渲染只影响浏览器展示，复制回答仍复制原始 Markdown 文本。
- 当前没有引入数学公式、Mermaid 或复杂引用标签；先保持最小实现。
- 流式 Markdown 的增量解析以后可以单独优化，本轮优先保证稳定可读。
