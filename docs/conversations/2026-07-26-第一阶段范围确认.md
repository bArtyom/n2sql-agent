# 第一阶段范围确认

## 背景

项目第一阶段需要以现有的知识库平台计划为准，并与总体计划保持一致。

## 已确认结论

- 第一阶段目标是独立重建参考 WeKnora 工程形态的通用文档知识库问答平台。
- `n2sql-agent` 是唯一的实现目录；WeKnora 仅供参考，不直接复制或复用其源码。
- 当前范围只包含知识库、文档上传与处理、文档检索、带引用的问答、模型配置和本地运行能力。
- 总体计划已同步为上述范围；后续领域业务能力如有需要，另行规划。
- 首版支持 Markdown、TXT 与可提取文本的 PDF；使用 PostgreSQL + pgvector 和本地挂载文件卷。
- Compose 只启动 PostgreSQL；前端与后端以本机开发模式运行。
- 文档通过数据库任务表和 Go worker 异步处理；问答通过 SSE 流式输出并展示引用。

## 当前小计划

- 当前小计划为“工程与本地运行底座”：前端技术路线已确认；待确定最小 Docker Compose 服务组合，并补齐后端、前端和 Docker Compose 的基础目录与开发配置，保持健康检查可用。

## 下一步

- 提供模型 Provider 配置的读取与更新接口，再接入连通性检查。

## 待确认
