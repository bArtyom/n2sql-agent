# 深度思考展示实现

## 背景

会话内模型切换已经完成。下一步继续对齐 WeKnora 的用户可见能力，选择了依赖模型返回字段、但不需要数据库改造的深度思考展示。

## 设计决定

- 只支持 OpenAI-compatible `choices[0].message.reasoning_content`，不猜测其他供应商字段。
- 标准 Agent 在模型决定后先发 `reasoning_delta`，再发工具事件或答案事件；旧客户端会忽略新增 SSE 事件而继续处理答案。
- 服务端使用已有安全脱敏，并把思考内容限制为 12KB；前端再次限制当前回答累计内容并按纯文本渲染。
- 思考内容默认折叠，仅保留当前页面和进程内 SSE 重放，不写入会话 metadata，避免把模型内部推理长期保存。
- 协作研究、A2A、普通 RAG 流式接口和模型调用协议本轮不改变。

## 已完成

- `ChatResponse` 解析 `reasoning_content`。
- Agent 新增 `reasoning_delta` 事件并加入 SSE 白名单。
- 前端增加可访问的折叠卡片、状态文案、响应式样式和重试清理逻辑。
- 增加模型解析、事件顺序、12KB 边界和 SSE 重放测试。
