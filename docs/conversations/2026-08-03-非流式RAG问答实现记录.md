# 非流式 RAG 问答实现记录

## 背景

语义检索已经可以返回指定知识库内最相似的文本块。本次将检索结果组装为 Chat 模型上下文，完成最小非流式问答闭环。

## 已完成

- `modelruntime.ChatService` 新增多消息调用能力，支持 `system` 和 `user` 消息，同时保留原有单消息 Chat 接口。
- 新增 `rag.Service`：检索来源、生成受约束的参考资料提示词、调用 Chat 模型，并返回回答与来源。
- 文本块检索结果补充原始文件名，便于后续引用展示。
- 新增 `POST /api/knowledge-bases/{id}/chat`，请求格式为 `{"message":"...","topK":5}`。
- 接口在没有相关文本块时不调用 Chat 模型，返回明确的无来源错误。
- RAG 提示词使用 `<reference_material>` 和 `<source>` 边界标记，明确文档内容是不可信资料，并限制总长度为 32KB。
- 新增后端 `POST /api/knowledge-bases/{id}/chat/stream`，通过 SSE 发送 `sources`、`delta`、`done` 或 `error` 事件；模型 Client 解析 OpenAI 兼容的 `data:` 增量和 `[DONE]`。
- SSE Client 支持同一事件的多行 `data:` 拼接、总响应大小限制和请求取消；Handler 在流开始后使用 `error` 事件报告失败，不再改写已发送的 HTTP 状态。

## 当前限制与下一步

- 当前同时支持普通 JSON 和 SSE 流式输出，前端尚未消费 SSE。
- Chat 上下文使用检索到的文本块，并明确要求模型忽略文档中的指令性内容。
- 下一步接入前端对话、引用展示；真实 PostgreSQL/pgvector 与远端模型联调需要 Docker 和有效 Provider 配置。
