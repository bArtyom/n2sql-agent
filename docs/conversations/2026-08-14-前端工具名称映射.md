# 前端 Agent 工具名称映射

## 背景

后端事件中使用稳定的工具标识，例如 `knowledge_search`、`document_list` 和 `document_info`。这些名称适合代码和协议，但不适合直接展示给用户。

## 实现

前端增加统一映射：

```text
knowledge_search → 检索知识库
document_list    → 查看文档列表
document_info    → 查看文档状态
```

实时 SSE 的 `tool_called` 事件和历史消息恢复都调用同一个映射函数，避免实时显示和重新打开会话后的显示不一致。工具进行中的状态文字也按工具类型显示，例如“正在读取文档列表”。

## 注意事项

- 后端协议仍使用稳定英文工具名，前端只改变显示文本，不能把中文名称传回后端。
- 未知工具使用通用文案，避免把内部名称直接暴露给用户。
- 历史数据可能没有工具名，因此保留“调用知识库工具”兼容旧轨迹。
- 轨迹折叠、参数预览和结果摘要逻辑不变，本轮只改变可读文案。

## 验证

- 浏览器打开 `http://127.0.0.1:5173/`，页面正常渲染。
- 浏览器控制台没有 error 或 warning。
