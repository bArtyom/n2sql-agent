# Agent 运行轨迹前端展示

## 背景

后端 Agent Engine 已经通过 SSE 发出运行生命周期事件，但标准 Agent 模式的前端只显示“正在查找资料”和最终答案，用户无法看到 Agent 是否调用了工具、检索是否完成、失败发生在哪一步。

## 本轮完成

- `App.vue` 新增 `AgentEvent` 前端模型。
- `consumeSSEBlock` 将已有事件转换为可读标签：开始运行、调用知识库工具、检索完成、开始生成答案、Agent 完成/失败/取消。
- 轨迹保留最近 12 条，避免长时间运行撑大页面。
- 工具事件继续合并引用来源；研究模式使用独立的研究轨迹，不与标准 Agent 混淆。
- `styles.css` 增加成功、进行中、失败三种状态的轻量视觉标记。

## 调用链

用户提交问题 → `agent-chat/stream` → 后端 Engine 发 SSE → `consumeSSEBlock` 解析 → `agentEvents` 更新 → Vue 渲染运行轨迹和引用。

## 验证

- `npm run build` 通过。
- 使用本地 mock SSE 在真实浏览器中验证了四步轨迹和答案展示。
- 未连接真实 PostgreSQL 或模型服务，不代表真实模型端到端验证完成。

## 下一步

继续做 Agent/RAG 用户可见能力，例如检索参数与过滤、引用展开体验或重新生成；暂不扩写大规模测试和评测。
