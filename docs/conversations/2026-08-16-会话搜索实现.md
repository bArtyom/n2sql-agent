# 会话搜索实现记录

## 已完成

- 会话存储新增 `Search`，只返回当前知识库、当前管理员拥有的会话。
- SQL 通过会话标题或 `conversation_messages.content` 子查询匹配关键词，并沿用现有排序。
- Handler 支持 `q`、`limit` 查询参数，服务层负责长度与上限校验。
- 前端会话栏新增搜索输入框，采用 250ms 防抖；无结果时显示提示，清空后恢复完整列表。
- 用户确认暂时只保留会话标题搜索；历史消息跨会话搜索和全文索引先搁置，后续在有明确性能需求时再单独评估。
- 会话列表增加分页响应：后端使用 `limit + 1` 判断 `has_more`，前端按页追加列表；标题搜索和普通列表都限制单次返回量。
