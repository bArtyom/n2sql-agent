# RAG 相似度距离阈值

## 背景

用户确认继续参照 WeKnora 完善 Agent/RAG，但暂时冻结没有明确对标证据的 Multi-Agent、A2A 扩展。WeKnora 的检索配置包含向量阈值；本项目 pgvector 返回的是 distance，数值越小越相似。

## 本轮完成

- 标准 Agent 请求增加 `similarity_threshold`，省略时使用 `0.65`。
- `agent.KnowledgeSearchTool` 保存每次请求的距离上限，只把 `distance <= threshold` 的结果作为证据。
- Handler、Service 和 Tool 三层校验阈值必须大于 0 且不超过 1；幂等请求哈希也包含该值。
- 前端问答台增加“距离上限”滑块，当前只对标准 Agent 生效；研究模式和 A2A 保持默认阈值。

## 验证

- `go test ./internal/agent ./internal/agentservice ./internal/handler`
- `npm run build`
- 浏览器打开本地前端，确认标准 Agent 下显示阈值滑块，默认值为 `0.65`。
