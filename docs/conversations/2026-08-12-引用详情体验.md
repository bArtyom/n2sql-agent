# 引用详情体验

## 背景

WeKnora 的 RAG 结果不仅返回最终文本，还需要让用户知道答案依据了哪份资料。本项目后端已经通过 SSE 和普通响应返回 `sources`，本轮集中处理重复性的前端展示工作。

## 本轮完成

- 引用展示从 `<details>` 折叠块改为来源卡片。
- 卡片显示序号、文件名、段落位置、检索距离和正文预览。
- 点击卡片打开右侧原文详情抽屉，展示完整片段。
- 支持点击遮罩、关闭按钮和 `Escape` 键关闭。
- 切换知识库、创建新知识库或发送新问题时自动关闭旧引用详情，避免显示过期来源。
- 保留“引用内容是外部不可信资料，仅作为事实参考”的提示。

## 入口到结果

```text
SSE/普通响应 sources
  → App.vue parseSources / mergeSources
  → 消息上的 source 卡片
  → selectedSource
  → 右侧 source-panel 展示完整原文
```

## 验证

- `npm run build` 通过。
- 启动本地 Vite 后，浏览器页面可加载；当前无真实模型响应，因此未伪造“点击真实引用”的验证结果。
