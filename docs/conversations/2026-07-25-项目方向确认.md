# 项目方向确认

## 已确认决策

- 第一阶段不实现 NL2SQL、SQLite Schema 同步或 SQL 执行。
- 优先复刻 WeKnora 的项目形态与成熟通用能力，先形成完整、可运行的基础平台。
- SQL 相关能力等待基础平台稳定、成熟后，再作为后续业务方向评估和接入。
- 第一阶段包含最小可用前端，以完成知识库、文档处理、检索和对话的端到端体验；视觉细节后置。
- 仅参考 WeKnora 的功能与架构，所有项目代码独立重写，不直接复制或复用上游源码。
- 后端、前端和基础设施遵循 WeKnora 的技术栈；现有 Go 服务骨架继续作为后端起点。
- 采用分阶段交付：先建设可运行的知识库与对话最小闭环，再逐步补齐高级功能。
- 本地开发的数据库、缓存、向量数据库、对象存储等依赖统一通过 Docker Compose 管理；先启用最小服务组合，再按需扩展。
- 第一阶段优先使用兼容 OpenAI API 的外部模型服务，并预留 Ollama 适配接口以支持后续本地模型运行。
- 第一阶段采用单个本地管理员模式；数据模型为后续用户、工作区和权限能力预留扩展空间。
- 所有后续功能遵循“小闭环优先、逐步补齐”的开发方式。

## 对计划的影响

- 当前已完成的 Go 服务骨架可作为复刻工作的起点。
- 后续工作将转向梳理并分阶段实现 WeKnora 的工程结构、配置、模型接入、知识库、文档处理、检索与对话能力。

## 待确认

- 第一阶段计划的验收范围与每个小闭环的先后顺序。
