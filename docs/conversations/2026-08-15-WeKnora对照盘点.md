# WeKnora 对照盘点（Agent/RAG 用户体验缺口）

## 背景

用户要求做一轮"WeKnora 对照缺口 + Agent/RAG 用户体验"的小范围盘点，再确定下一个可运行切片。盘点结论见 docs/plans/2026-08-15-WeKnora对照盘点.md（含 18 项差异矩阵与切片评估）。

## 已确认结论

- 盘点范围：只列"用户在聊天界面能直接看到/操作"的能力；企业级功能（RBAC、IM、数据源、Wiki、多租户）不列入。
- 当前项目 Agent/RAG 用户可见能力已相当完整：三种问答模式、RAG 参数控制、引用卡片+原文懒加载、Agent 轨迹+运行摘要、检索流水线详情、会话历史恢复、追问建议。
- 最大差距集中在：停止生成（机制已存在只缺触发链路）、会话管理体验（置顶/分组/自动标题）、正文内引用标记、实时 RAG 进度、消息级操作。
- 明确不做：Web 搜索/抓取（边界外）、数据库工具（无 SQL 主题）、历史消息全文索引（大）、工具审批（工具全只读）、多模态图片（模型未验证）。

## 下一步（建议顺序）

1. 首选切片：**停止生成**——engine 每步查 ctx.Err()、context.Canceled→run_canceled、AgentRun.Cancel 已实现；只需 handler 注册 cancel 到 hub + 新增 stop 接口 + 前端按钮。与断线恢复（不取消）语义区分需写明。
2. 次选：会话置顶 + 日期分组（is_pinned 字段，风险最低）。
3. 可穿插小切片：会话自动标题、会话更多菜单（清空/复制 Markdown）、追问建议"换一批"。
4. 中规模（待确认）：正文内引用标记、实时 RAG 流水线进度、断流续传。

## 仍未确定
