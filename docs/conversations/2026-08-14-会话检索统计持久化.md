# 会话检索统计持久化

## 背景

检索详情最初只存在前端运行时状态。切换会话或刷新页面后，回答正文还在，但向量召回、关键词过滤和 Rerank 信息会丢失。

## 已确认结论

- 在 `conversation_messages` 增加 `metadata JSONB NOT NULL DEFAULT '{}'`，不修改正文和历史消息结构。
- 只有助手消息写入检索统计和查询改写状态，用户消息保持空对象。
- Agent 非流式和 SSE 保存路径共用同一个 `SaveExchangeWithMetadata` 入口。
- 历史消息 API 返回可选 `metadata`，前端映射回 `message.retrieval` 和 `message.queryRewrite`。
- 历史旧消息的 metadata 是 `{}`，前端不显示检索详情，保持兼容。
- metadata 只保存有界计数和状态，不保存 API Key、完整查询改写文本或模型原始响应。
