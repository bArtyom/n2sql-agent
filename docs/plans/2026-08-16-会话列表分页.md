# 会话列表分页规格

## 接口

`GET /api/knowledge-bases/{id}/conversations?limit=30&offset=0&q=关键词`

响应统一为：

```json
{
  "items": [],
  "has_more": false,
  "offset": 0,
  "limit": 30
}
```

## 约束

- `limit` 默认 50，最大 100；前端当前使用 30。
- `offset` 从 0 开始，不能为负数。
- `q` 仍然只匹配会话标题，不扫描消息正文。
- 数据库多取一条记录判断 `has_more`，不会额外执行 `COUNT(*)`。
