# 会话消息搜索索引规格

## API

- `GET /api/knowledge-bases/{id}/conversations?q=...`：只搜索会话标题，继续返回会话列表。
- `GET /api/knowledge-bases/{id}/conversations/messages/search?q=...&limit=...`：搜索历史消息，返回会话摘要、消息 ID、角色、摘要、首次字面命中位置和时间。

## 数据库

- `conversations.title_search` 使用 `to_tsvector('simple', title)` 生成列，并建立 GIN 索引。
- `conversation_messages.content_search` 使用 `to_tsvector('simple', content)` 生成列，并建立 GIN 索引。
- 标题的模糊匹配额外建立 `lower(title) gin_trgm_ops` 索引；消息搜索使用 `content_search @@ plainto_tsquery(...)`，避免扫描全部消息。

## 边界

- 搜索仍按当前知识库和当前管理员隔离。
- 消息摘要最多返回 240 个字符；命中位置是消息正文中关键词的首次字面位置，全文检索负责判断是否命中。
- 暂不返回 HTML 高亮，避免把数据库内容直接作为 HTML 注入前端。
