# WeKnora 对照盘点：Agent/RAG 用户体验缺口

> 日期：2026-08-15。范围：只盘点"用户在聊天/问答界面能直接看到或操作的能力"，对照参考仓库 /Users/lsp/project/WeKnora（v0.7.x，Go + Vue 3）。企业级功能（多租户、RBAC、IM、数据源连接器、部署运维）不在盘点范围。

## 当前项目能力清单（n2sql-agent）

依据 README、PROJECT_STATUS.md、第二阶段计划、docs/conversations/ 与 frontend/src/App.vue（1904 行单文件前端）整理。

### 知识库与文档

- 知识库：创建、删除（级联清理 + 检索缓存失效 + 本地文件清理）、列表。
- 文档：上传（Markdown/TXT/PDF，多文件、拖拽、10MB 上限）、处理状态轮询、列表、删除、正文预览（按 chunk 起始位置分页、继续读取、字节上限）。

### 问答模式与参数控制

- 三种模式：标准 Agent（写会话历史）/ 协作研究（Researcher 轨迹，不写历史）/ A2A 异步任务（PostgreSQL 持久化 + 轮询）。
- 参数：topK（3/5/8/12/20）、相似度阈值滑块（默认 0.65）、关键词阈值（0.10）、查询改写开关、按文档 ID 过滤检索范围。
- 流式 SSE：标准 Agent 带 run_id 断线恢复（进程内重放 + 事件去重）。

### 消息与回答展示

- 流式增量文本；完成后 Markdown 渲染（marked + DOMPurify）。
- 回答操作：复制回答、复制原文、失败后"重新生成"（仅标准 Agent、仅失败态）。
- 起步问题（3 条固定模板）+ 按需生成追问建议（最多 3 条 text/category，不写历史、正常回答不触发）。
- 没有：停止生成、消息删除/编辑、附件/图片上传、思考过程展示。

### 引用与证据

- 来源卡片：文件名、段落位置、匹配类型（vector/keyword/hybrid/document_read）、距离/重排分数、片段预览。
- 引用原文抽屉（懒加载完整 chunk）、正文预览面板。
- 提示注入安全说明；复制引用原文。
- Agent 工具轨迹与引用通过 source_keys 关联。

### Agent 过程可视化

- 运行轨迹卡片：run_started / tool_called / tool_finished / message_delta / run_finished 事件。
- 工具轨迹折叠展开：参数预览 + 结果摘要（有界持久化，最多 32 条、每段 512 字节）。
- 运行摘要 stats：步骤数、模型/工具调用数、失败数、Token、耗时。
- 工具中文名映射（检索知识库/查看文档列表/查看文档状态/读取文档正文）。
- 工具失败 fail-closed：对外固定提示，不泄露内部错误。

### 检索流水线详情（事后面板）

- 向量/关键词召回数量、关键词阈值过滤、去重、Rerank 前后、距离过滤、降级状态、改写启用/变体数。
- 随消息持久化，历史会话可恢复。

### 会话与历史

- 会话：新建、重命名、删除、列表、消息读取。
- 历史恢复：引用卡片、Agent 轨迹、运行摘要、检索统计（metadata JSONB）。
- 没有：会话搜索、置顶、分组、批量管理、导出。

### 模型与设置

- 模型服务设置：服务名、Base URL、聊天模型、嵌入模型、Rerank 可选；连接/聊天/嵌入三种测试。
- API Key 只存后端 .env；ALLOWED_HOSTS 防 SSRF。

### 后端能力边界（已有但用户不可见）

- 混合检索（向量 + tsvector 关键词 + RRF）、Rerank、Query Rewrite、缓存、父子 chunk、HNSW。
- 只读 MCP 适配、最小 A2A、Multi-Agent（Supervisor/Researcher/Answerer）。
- 会话消息 metadata JSONB；检索缓存失效；结构化日志与基础 metrics。

## WeKnora 对照能力清单（用户可见、可迁移）

调研来源：子代理通读 frontend/src/views/chat/、frontend/src/components/、frontend/src/api/、internal/agent/tools/ + 主代理抽查 README_CN.md v0.7.1 与关键组件。企业级能力（RBAC、IM、数据源、Wiki 写作、多租户）不列入。

### 输入与附件

- 多行输入框：Enter 发送、Shift/Ctrl+Enter 换行、输入时触发 @ 面板。
- 图片上传：最多 5 张（jpg/png/gif/webp/10MB）、缩略图预览、可移除、粘贴/拖拽即入列；随消息发送给多模态模型（临时文档 attachment_id，失败回退 base64）。
- 附件上传：最多 5 个文件、实时上传进度、解析状态轮询；附件解析作为 pipeline 步骤展示摘要。
- @ 提及菜单：可搜索选择知识库、文件、标签、MCP 服务、Skill；已选资源 chips 内联展示可移除。
- 停止生成：回复中输入栏出现停止按钮，立即中止流并标记消息结束。
- 模型选择器：输入栏切换聊天模型 + 快捷"添加模型"。
- Web 搜索开关按钮：一键开/关，未配置时引导去设置。
- 会话请求状态记忆：重进会话自动恢复上次的智能体/KB/Web 搜索/模型选择。

### 消息展示与交互

- 富 Markdown：表格、代码高亮、KaTeX 公式、Mermaid 图。
- 打字机平滑输出（节流逐字 + 全部揭示后才显示操作栏）。
- 回答操作栏：复制回答、添加到知识库（预填问题+回答打开文档编辑器）、请求信息按钮、兜底提示。
- 回答内图片点击放大预览。
- 深度思考折叠卡片（非 Agent 模式）+"思考中"全局指示器。
- 回到底部浮动按钮、平滑滚动跟随。
- 渲染完成事件驱动后续动作（完整渲染后才显示追问建议）。
- 消息来源渠道标签（web/api/im）。
- 用户消息内附件卡片 → 右侧文档预览抽屉（可拖拽调宽）。

### Agent 过程可视化

- Agent 步骤流式时间线：每次工具调用"图标+名称+运行/完成状态"卡片逐条流出，失败显示错误态。
- 中间步骤折叠/展开：完成后整棵时间线折叠为一行摘要。
- 工具结果类型化渲染（15 个组件）：语义搜索结果按文档分组+命中词高亮、分块详情、文档信息、数据库结果表格、Web 搜索结果、grep 高亮、未知类型原始输出兜底。
- 工具结果摘要行：语义搜索命中数、Web 搜索"N 条结果"等。
- 思考步骤卡片：第 n/总数徽章、可展开思考内容、流式滚动到底。
- MCP 工具人工审批卡：批准/拒绝、30s 倒计时、可编辑 JSON 参数（校验非法 JSON、标记修改）。
- MCP OAuth 授权卡：授权/跳过、跳转授权页并轮询。
- RAG 管道时间线：树状进度（检索+思考+完成），完成后折叠为"搜索完成 · N 文档/M 网页"，点步骤打开引用抽屉。
- 工具名本地化：内置工具中文名、MCP 工具名格式化、输出清洗 UUID/ID。

### 引用与证据

- 正文内引用标签：模型输出 <kb/> / <web/>，前端转可点击引用 pill，悬停浮层预览（ChatCitationFloat）。
- 引用抽屉 420px 右侧面板：文档/网页/工具三类分区，文档引用可展开全文+跳转知识库。
- 三类可点击引用：KB → 抽屉定位 chunk；Web → 新窗口；Wiki → 阅读抽屉。
- 同文档多分块引用合并展示。
- 非 Agent 模式知识引用区块：按文档分组的引用列表 + 分块弹层预览。

### 会话与历史

- 会话标题：双击行内重命名 + 自动生成标题（SSE session_title 事件）。
- 会话更多菜单：置顶/取消置顶、重命名、复制会话 ID/链接、复制整个会话为 Markdown、新窗口、清空消息（二次确认）、删除（二次确认）。

### 候选切片评估

**首选：停止生成（#1）**
- 现状缺口：回答生成中（尤其 Agent 多轮检索 + 长回答）无法中断，只能等超时。
- 现有基础：agentruntime.Engine 每步检查 ctx.Err()，context.Canceled 映射为 run_canceled 事件；AgentRun.Cancel() 已实现并有状态机保护；hub 已按 runID 注册 knowledgeBaseID。
- 实现路径（已验证代码）：
  1. handler 创建可取消的执行上下文（context.WithCancel 包在 WithoutCancel 之外），把 cancel 函数注册进 hub（run 结构加 cancel 字段或独立 map）。
  2. 新增 POST /api/knowledge-bases/{id}/agent-runs/{runID}/stop：校验知识库归属 → 调 cancel → engine 下一步骤收到 ctx.Err → 发 run_canceled → 前端收到。
  3. 前端：streaming 时输入栏/消息区显示"停止"按钮，调用 stop 接口；收到 run_canceled 标记该回答为已停止（不显示"重新生成"，因为未失败）。
- 与断线恢复的语义区分：断连 = 不取消（继续跑，hub 重放）；用户主动停止 = 取消（run_canceled）。两者共存的边界需要在文档与代码注释中写明。
- 验证：handler 集成测试（停止后收到 run_canceled、运行不再完成）+ 前端浏览器冒烟。

**次选：会话置顶 + 日期分组（#2）**
- 增量小：conversations 表加 is_pinned 字段（迁移）+ 列表按置顶/日期分组；后端排序或前端分组均可。
- 无模型调用、无协议变更，风险最低。

**可立即做的小切片（随主线穿插）**
- #3 会话自动标题：首轮问答后按用户问题截断生成标题（或复用总结模型），改动小、可见性强。
- #7 会话更多菜单：清空消息（后端加清空接口或复用删除）、复制会话为 Markdown（纯前端）。
- #4 追问建议"换一批"：follow-up-suggestions 接口加 regenerate 语义即可。

**中规模切片（后续轮次）**
- #5 正文内引用标记：需改 Agent 提示词（要求输出 <kb/> 标签）+ 前端渲染管道 + 引用解析兜底；与现有引用卡片可并存。
- #6 实时 RAG 流水线进度：SSE 增加 pipeline 阶段事件，前端渲染步骤树；已有工具轨迹与统计字段基础，但需定义新事件类型并保持向后兼容。
- #9 断流续传（刷新后恢复未完成回答）：需要在会话保存时记录"未完成"状态与 run_id，刷新后重放剩余事件；与 #1 停止生成共享 hub 机制。

### 明确不做（边界）

- Web 搜索/抓取（#15）：超出"文档知识库问答"边界，需要外部搜索供应商配置。
- 数据库查询/数据分析工具：项目明确不引入 SQL/N2SQL 主题。
- 会话历史全文索引搜索（#14）：大规模后置。
- 工具审批与 OAuth（#16）：当前工具全部只读，审批无实际对象。
- 多模态图片上传（#10 的图片部分）：需要多模态模型支持，当前聊天模型未验证。

### 建议下一步

先做**停止生成**切片（小而完整、机制已存在、用户痛点明确），完成后按"次选 + 可立即做的小切片"顺序穿插；中规模切片待用户确认后再排期。
