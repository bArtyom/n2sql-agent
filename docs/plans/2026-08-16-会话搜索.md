# 会话搜索开发规格

## 目标

在当前知识库范围内，支持按会话标题和历史消息内容搜索会话，并把搜索结果复用到现有会话列表和选择流程。

## 接口契约

`GET /api/knowledge-bases/{id}/conversations?q={query}&limit={limit}`

- `q` 缺省或为空时保持原有列表行为。
- `q` 会去除首尾空白，最多 200 字节。
- `limit` 缺省为 50，允许范围为 1–100。
- 搜索必须同时限制 `knowledge_base_id` 和当前管理员，不能通过会话消息内容越权看到其他知识库数据。
- 结果继续按置顶、更新时间、ID 倒序排列。

## 实现边界

- 第一版使用 PostgreSQL 的大小写不敏感子串匹配，避免把用户输入拼进 `LIKE` 模式。
- 暂不引入全文搜索索引、搜索高亮或跨知识库搜索；数据量增大后再单独评估 `pg_trgm` 或全文检索。
- 前端输入采用 250ms 防抖，清空搜索恢复完整会话列表。

## 验证

- 后端：服务层校验空查询、超长查询和结果上限；Handler 校验 query 参数并转发搜索契约。
- 前端：`vue-tsc --noEmit` 与 Vite production build。
- 若本机 Go 工具链可用，再运行 `go test ./internal/conversation ./internal/handler`。
